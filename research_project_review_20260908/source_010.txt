## [KNOWN] + [EXACT application] 2.4. Denjoy–Koksma / Ostrowski bound

Şimdi:

[
\beta=\alpha-1=\log\_2(3/2).
]

Fractional parts değişmez:

[
{j\alpha}={j\beta}.
]

[

[
\mu=\frac1{2\ln2}

[

]

[
\left|
\sum\_{j=0}^{q\_m-1}g(x+j\beta)

\right|
\le1
]

[

]

olsun.

\boxed{

\sum\_i b\_i.

[

[
\boxed{

\le

\tag{2.4}
